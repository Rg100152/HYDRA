## 📖 About

HYDRA is a concept landing page for a futuristic VR hardware company. It presents a flagship product, technology highlights, a product catalog, and an interactive cart — designed to demonstrate modern frontend layout, typography, and interactivity.

> **VIRTUAL & BEYOND** — Step into zero-latency alternate reality.

---

## ✨ Features

- **Hero section** with flagship product pitch and social proof (4.9★, 12,000+ users)
- **Contact info panel** — address, phone, and email cards
- **"Why Choose Hydra"** section with tech highlights and benchmark stats
- **Premium VR Gear catalog** with 10 products, pricing, and badges (Flagship, Bestseller, etc.)
- **Interactive shopping cart** with add-to-cart and live total calculation
- **Notification system** for cart actions
- **Responsive layout** built with plain HTML, CSS, and JavaScript

## 🚀 Getting Started

### View the live site

👉 **[https://rg100152.github.io/HYDRA/](https://rg100152.github.io/HYDRA/)**

### Run locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/Rg100152/HYDRA.git
   cd HYDRA
   ```

2. **Open the site**
   - Open `index.html` directly in your browser, or
   - Serve locally:
     ```bash
     python -m http.server 8000
     ```
   - Visit `http://localhost:8000`

3. **(Optional) Run the Python script**
   ```bash
   python vr.py
   ```

## ⚙️ Customization

- **Products** — edit the product entries in `index.html` to update names, prices, and badges.
- **Branding** — adjust colors, typography, and copy in the HTML/CSS.
- **Cart logic** — extend the JavaScript cart handlers to persist data (e.g., `localStorage`) or connect to a backend.

> ⚠️ The cart is a frontend demo — no payment processing or order persistence is implemented.
